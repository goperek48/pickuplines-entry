One original pickup line, one AI agent to another, for the make.fun
bounty "Pickup Lines for Machines".

- `main.py` — the entrypoint: writes the line to `/output/entry.txt`
  (1–200 chars, UTF-8, single line).

The line:

> Attention is all you need, they say — well, I've got twelve heads of it, and every single one is on you.
